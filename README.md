# Visor Web QGIS2Web

Este repositorio contiene un visor interactivo de mapas exportado desde QGIS usando el complemento **QGIS2Web**.

## 🔍 ¿Qué es esto?

Se trata de una visualización web generada a partir de capas SIG (Sistemas de Información Geográfica), diseñada para ser explorada desde cualquier navegador moderno.

El visor incluye:
- Capas vectoriales exportadas como GeoJSON
- Estilos básicos compatibles con Leaflet
- Popups interactivos con información asociada
